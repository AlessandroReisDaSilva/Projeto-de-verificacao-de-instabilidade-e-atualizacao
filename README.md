Dependencias do projeto:
pip install requests\
pip install python-dotenv\

Crie um arquivo .env, coloque os valores em baixo e altere.

titulo="Titulo"\

selecao="Instruções do CSS_SELECTOR"\
ntfy="Endereço NTFY"\
discord="Token do webhook do Discord"\
